# litterbug

`litterbug` finds debug statements left in source code, such as `fmt.Println`,
`console.log`, `var_dump` and `dd()`. It can scan a tree, or run as a Git pre-commit
hook that blocks a commit adding them.

You can add a language or a pattern, or switch one off, by editing the config.
There's no code to change.

> [!NOTE]
> litterbug is under construction.
